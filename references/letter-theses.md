# Talking points for the application

The output is a set of points the user turns into their own letter. Not a letter.

## Format

4–6 points. Each one:

- **Point** – one sentence, plain words.
- **From the CV** – a verbatim quote that backs it.
- **From the vacancy** – a verbatim quote it answers.

## What to include

1. **Opening angle** – the one thing in the CV that matches the core of this vacancy. Start there.
2. **Best story** – one real project or result from the CV that the vacancy's main duty maps to.
3. **Second proof** – a different skill from the Must list, with evidence.
4. **The gap, said honestly** – the biggest real gap and one honest sentence about it
   (for example: "I haven't used X in production; the closest is Y").
5. **Why this company** – only if it can be tied to something real in the vacancy or from a searched fact. Otherwise leave it out.
6. **Ask or next step** – what the user wants to learn or discuss.

## Rules

- Every claim traces to the CV or something the user confirmed in this chat. No quote, no point.
- Never describe a team decision as the user's alone.
- No inflated words: "passionate", "rockstar", "extensive", "leveraged".
- Don't promise what the CV can't back (years, tools, seniority).
- Short sentences, plain English. Write as a person, not a press release.
- If a vacancy says not to use AI for the application, say so and don't produce the points. Tell the user instead.

## Full draft

Only if the user asks. Label it "draft – check every claim", reuse the same points, no new claims.
